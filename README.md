# ระบบเช็คชื่อผู้เรียน — Claude AI Class

เว็บสำหรับเช็คชื่อผู้เข้าเรียน ใช้ได้ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์ ผู้เรียนกด "เช็คชื่อ" แล้วเซ็นลายเซ็น ระบบจะบันทึกเวลาที่มา บอกว่าตรงเวลาหรือสาย และ**บันทึกลง Google Sheet ให้อัตโนมัติ**

- หน้าเว็บเป็นไฟล์ static: วางบน **GitHub Pages** ได้ฟรี
- ส่วนหลังบ้านคือ **Google Apps Script** ที่ผูกกับ Google Sheet ของคุณ
- ทุกเครื่องเห็นข้อมูลตรงกัน (อัปเดตทุก 8 วินาที)
- ถ้าเน็ตหลุดตอนเช็คชื่อ ข้อมูลจะถูกเก็บไว้ในเครื่องก่อน แล้วส่งเข้า Google Sheet ให้เองเมื่อกลับมาออนไลน์

## โครงสร้างไฟล์

```
.
├── index.html                    หน้าเว็บทั้งหมด (HTML + CSS + JavaScript ในไฟล์เดียว)
├── config.js                     ใส่ URL ของ Google Apps Script ที่นี่
├── google-apps-script/
│   ├── Code.gs                   โค้ดหลังบ้าน — คัดลอกไปวางใน Apps Script
│   └── appsscript.json           การตั้งค่าโปรเจกต์ Apps Script (เขตเวลา Asia/Bangkok)
├── sample/
│   └── roster-template.csv       ไฟล์ตัวอย่างรายชื่อ
└── README.md
```

## ขั้นตอนติดตั้ง

### 1. สร้าง Google Sheet และวางโค้ด Apps Script

1. สร้าง Google Sheet ใหม่ที่ [sheets.new](https://sheets.new) ตั้งชื่อเช่น `เช็คชื่อ Claude AI`
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้ง แล้ววางโค้ดทั้งหมดจาก `google-apps-script/Code.gs`
4. **เปลี่ยนรหัสผู้ดูแล** ที่บรรทัดบนสุด:
   ```js
   const ADMIN_KEY = 'ตั้งรหัสของคุณเอง';
   ```
5. ตั้งเขตเวลา: ไอคอนฟันเฟือง **Project Settings** → Time zone เลือก `(GMT+07:00) Bangkok`
6. กด 💾 บันทึก แล้วเลือกฟังก์ชัน `setup` ด้านบน → กด **Run**
   - Google จะขอสิทธิ์ → เลือกบัญชี → **Advanced → Go to (ชื่อโปรเจกต์) (unsafe) → Allow**
     (ขึ้นคำว่า unsafe เพราะเป็นสคริปต์ที่คุณเขียนเอง ยังไม่ผ่านการตรวจของ Google — ปกติสำหรับสคริปต์ส่วนตัว)
   - กลับไปดู Google Sheet จะมี 3 ชีตใหม่: **เช็คชื่อ / รายชื่อ / ตั้งค่า**

### 2. Deploy เป็น Web app

1. ใน Apps Script กด **Deploy → New deployment**
2. กดฟันเฟืองข้าง "Select type" → **Web app**
3. ตั้งค่า:
   - **Execute as:** `Me`
   - **Who has access:** `Anyone`
4. กด **Deploy** แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

### 3. ใส่ URL ใน config.js

เปิดไฟล์ `config.js` แล้ววาง URL:

```js
window.ATTENDANCE_CONFIG = {
  sheetsUrl: "https://script.google.com/macros/s/AKfycb..../exec",
  pollSeconds: 8
};
```

### 4. ขึ้น GitHub และเปิด GitHub Pages

1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ลากวางในหน้า repository ได้เลย หรือใช้ `git push`)
3. ไปที่ **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → **Save**
4. รอประมาณ 1 นาที จะได้ลิงก์ เช่น `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

> ⚠️ GitHub Pages ของ repository แบบ **Public** ใช้ได้ฟรี — ทุกคนเห็นโค้ดได้ แต่ **ไม่เห็นข้อมูลผู้เรียน** เพราะรายชื่อและการเช็คชื่อเก็บอยู่ใน Google Sheet ของคุณ ไม่ได้อยู่ในไฟล์บน GitHub (อย่า commit ไฟล์รายชื่อจริงขึ้น repository สาธารณะ)

### 5. นำเข้ารายชื่อผู้เรียน

เลือกวิธีใดวิธีหนึ่ง:

- **ผ่านหน้าเว็บ:** เปิดเว็บ → เมนู **จัดการ** → ใส่รหัสผู้ดูแล → ลากไฟล์ CSV/Excel มาวาง
  (รองรับไฟล์จาก Google Form ที่ลงทะเบียนหลายคนในแถวเดียว เช่น คอลัมน์ "ชื่อ-นามสกุล 2", "ชื่อ-นามสกุล 3")
- **พิมพ์/วางในชีต "รายชื่อ" โดยตรง:** ใส่ชื่อในคอลัมน์ `ชื่อ-นามสกุล` คอลัมน์ `id` ปล่อยว่างได้ ระบบจะเติมให้

## การใช้งาน

| สิ่งที่ทำ | วิธี |
|---|---|
| เช็คชื่อ | กดชื่อตัวเอง → เซ็นในกรอบ → **ยืนยันเข้าเรียน** |
| ค้นหา | พิมพ์ชื่อ หรือชื่อบริษัท ในช่องค้นหา |
| ดูย้อนหลัง | เลือกวันที่จากเมนูมุมขวาของแถบค้นหา |
| ตั้งเวลาเริ่มเรียน / เกณฑ์มาสาย | เมนู **จัดการ → ตั้งค่าคลาส** (หรือแก้ในชีต "ตั้งค่า") |
| ยกเลิกการเช็คชื่อ | (ผู้ดูแล) กดการ์ดของคนที่เช็คแล้ว → **ยกเลิกการเช็คชื่อ** |
| แท็บเล็ตหน้าห้อง | เมนู **จัดการ → โหมดคีออสก์** ซ่อนเมนูจัดการ ออกด้วย PIN 4 หลัก |
| ส่งออก | เมนู **จัดการ → ส่งออก** เป็น CSV / Excel หรือคัดลอกไปวางที่อื่น |

### ข้อมูลใน Google Sheet

ชีต **เช็คชื่อ** — 1 แถวต่อ 1 การเช็คชื่อ

| วันที่ | เวลา | ชื่อ-นามสกุล | บริษัท/หน่วยงาน | สถานะ | สาย (นาที) | อุปกรณ์ | ลายเซ็น | ไฟล์ลายเซ็น |
|---|---|---|---|---|---|---|---|---|
| 2026-11-14 | 08:52:10 | นางสาว... | บริษัท ... | ตรงเวลา | | มือถือ | (รูปลายเซ็น) | เปิดไฟล์ |

- คอลัมน์ `id`, `timestamp`, `sigdata` ถูกซ่อนไว้ ระบบใช้ภายใน — **อย่าลบ**
- รูปลายเซ็นยังถูกเก็บเป็นไฟล์ PNG ในโฟลเดอร์ `ลายเซ็นเช็คชื่อ` บน Google Drive ของคุณ
  (ปิดได้โดยตั้ง `SAVE_SIGNATURE_TO_DRIVE = false` ใน Code.gs)

## เมื่อแก้ไขโค้ด Code.gs ภายหลัง

ต้อง Deploy เวอร์ชันใหม่ ไม่งั้นเว็บยังใช้โค้ดเก่า:

**Deploy → Manage deployments → ✏️ (Edit) → Version: New version → Deploy**

(วิธีนี้ URL เดิมยังใช้ได้ ไม่ต้องแก้ config.js)

## แก้ปัญหาเบื้องต้น

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| มุมบนขึ้น "บันทึกในเครื่องนี้" | ยังไม่ได้ใส่ `sheetsUrl` ใน config.js |
| ขึ้น "ออฟไลน์" ตลอด | URL ผิด หรือ Deploy ไม่ได้ตั้ง **Who has access: Anyone** |
| ขึ้น "ตอบกลับไม่ใช่ JSON" | ยังไม่ได้กด Run `setup` / ยังไม่อนุญาตสิทธิ์ หรือใช้ URL ที่ลงท้าย `/dev` แทน `/exec` |
| รหัสผู้ดูแลไม่ถูกต้อง | แก้ `ADMIN_KEY` แล้วยังไม่ได้ Deploy เวอร์ชันใหม่ |
| เวลาเพี้ยน 7 ชั่วโมง | ตั้ง Time zone ของโปรเจกต์ Apps Script เป็น Bangkok |
| แก้ config.js แล้วเว็บไม่เปลี่ยน | GitHub Pages ใช้เวลาอัปเดต 1–2 นาที ลองรีเฟรชแบบล้างแคช (Ctrl/⌘ + Shift + R) |

## ความปลอดภัย

- ใครที่มีลิงก์เว็บ **เช็คชื่อได้** (ตั้งใจให้ผู้เรียนใช้มือถือตัวเองได้) แต่ **จัดการรายชื่อ / ตั้งค่า / ยกเลิกการเช็คชื่อ** ต้องมีรหัสผู้ดูแล
- `ADMIN_KEY` อยู่ใน Apps Script เท่านั้น ไม่ได้อยู่บน GitHub
- เช็คชื่อซ้ำคนเดิมในวันเดียวกันไม่ได้ (ระบบตรวจซ้ำให้)
